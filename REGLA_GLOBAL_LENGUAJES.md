# Regla global de lenguajes — Estructuras Computacionales

A partir de esta corrección seguiremos esta política en todos los ejercicios:

1. Todo lenguaje que participe realmente en el algoritmo o firmware debe ser visible en GitHub.
2. No se ocultará C para forzar Assembly 100%, ni Assembly para forzar C 100%.
3. Un repositorio solo debe mostrar 100% de un lenguaje cuando de verdad la implementación sea pura.
4. FreeRTOS se documenta como tecnología/arquitectura; el lenguaje normalmente seguirá siendo C.
5. PowerShell, CMake, JSON, VS Code, Markdown y herramientas auxiliares se excluyen de Linguist.
6. Si existe una versión pura y otra híbrida, se documentarán como implementaciones diferentes.
7. Los porcentajes de GitHub reflejan bytes de código detectables, no importancia pedagógica.
