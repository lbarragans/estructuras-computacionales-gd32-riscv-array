# Regla global de lenguajes

Cada lenguaje realmente utilizado por una implementacion debe aparecer en
GitHub.

En este repositorio:

- C cuenta porque la referencia y FreeRTOS estan escritos en C.
- Ensamblador RISC-V cuenta porque la referencia contiene rutinas `.S` y existe
  ademas un apartado puro.
- FreeRTOS es una tecnologia/RTOS, no un lenguaje.
- PowerShell, CMake, JSON y Markdown son auxiliares.

No se fuerza artificialmente ningun porcentaje.
