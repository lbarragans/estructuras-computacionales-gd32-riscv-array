# 08 - Hibrida con estadisticas extendidas

## Lenguajes

C + Assembly RISC-V.

## Filosofia

No todo debe escribirse en el lenguaje de menor nivel.

En esta version:

- C calcula la suma.
- Assembly calcula minimo y cantidad de positivos.

## Pregunta de ingenieria

¿Que parte merece Assembly?

La respuesta puede depender de:

- rendimiento;
- acceso a instrucciones especiales;
- necesidad de control;
- mantenibilidad;
- habilidades del equipo.
